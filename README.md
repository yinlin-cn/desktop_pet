# 爱莉爱莉爱（ELYSIA 桌面宠物播放器）

一个基于 Qt Widgets + C++17 开发的 Windows 桌面宠物小工具：以“爱莉希雅”形象的透明动画宠物常驻桌面，可点按、拖动、说话、随机移动，并附带一个可以“合体”在宠物下方的迷你音乐播放器。

程序内部名称与托盘提示为“爱莉爱莉爱”，编译目标为 `ELYSIA.exe`。

## 主要功能

- 桌面宠物
  - 无边框、透明背景、始终置顶、不占用任务栏，通过系统托盘常驻。
  - 使用 GIF 动画表现“闲置 / 单击 / 拖动”三种状态，默认各配置一套爱莉希雅素材。
  - 支持单击触发动画与台词、左键拖动、右键打开与托盘相同的菜单。
  - 开启“爱莉移动”后，每隔约 5 秒自动移动到屏幕内随机位置，动画时长约 1 秒。
  - 支持显示气泡台词，台词随机从“闲置 / 单击 / 拖动”三组中各 5 条中选取，默认显示约 3 秒。
- 迷你音乐播放器
  - 默认停靠在屏幕右下角，支持鼠标拖动，无边框透明背景。
  - 提供上一首、播放 / 暂停、下一首按钮。
  - 播放模式按钮按“随机播放 -> 列表循环 -> 单曲循环”循环切换。
  - 可与桌面宠物“合体”：宠物跟随播放器移动，合体间距可配置。
- 三种音乐来源模式
  - 初始模式：播放编译进程序资源的两首内置 WAV。
  - 本地模式：扫描运行目录下的 `music` 文件夹，或用户指定的自定义文件夹中的 WAV 文件。
  - 软件模式：由播放器向外部音乐软件模拟发送快捷键，不通过本项目解码播放。
- 可深度自定义
  - 可替换闲置 / 单击 / 拖动 GIF、设置窗口背景、播放器背景、内置音乐、台词文本颜色、宠物尺寸、合体间距等。
  - 可单独编辑三组共 15 条台词。
  - 自定义设置与台词均写入运行目录下的文本文件，重启后继续生效。

## 环境要求

- Windows 10 / 11（代码使用 `windows.h`、`winmm` MCI 与 `keybd_event`，不跨平台）
- C++17
- Qt 6 的 `widgets`、`multimedia` 模块
- 开发配置参考：Qt Creator 18 + Qt 6.8.2 MinGW 64-bit

## 快速使用

1. 启动程序后，透明宠物会出现在桌面上，迷你播放器默认停靠在屏幕右下角。
2. 左键点一下宠物：播放单击动画并显示一句随机台词。
3. 左键按住宠物拖动：播放拖动动画并可把宠物放到任意位置。
4. 右键点击宠物，或点击系统托盘图标：打开功能菜单。
5. 双击托盘图标：重新显示已隐藏的宠物。
6. 从托盘菜单选择“退出”结束程序；宠物窗口没有普通标题栏和关闭按钮。

### 托盘菜单

| 菜单项 | 作用 |
| --- | --- |
| 显示爱莉 | 显示或隐藏桌面宠物 |
| 显示播放器 | 显示或隐藏迷你播放器 |
| 爱莉移动 | 开启或关闭自动随机移动 |
| 爱莉合体 | 让宠物吸附并跟随播放器移动 |
| 爱莉说话 | 开启或关闭气泡台词 |
| 播放音乐 | 开启或关闭本程序自己的音乐播放 |
| 初始音乐 | 切换到内置的两首 WAV |
| 本地音乐 | 切换到本地 `music` 文件夹中的 WAV |
| 软件音乐 | 切换到外部软件控制模式 |
| 设置 | 打开设置窗口 |
| 退出 | 退出程序 |

托盘中的即时开关不会写入配置文件；如需让常规设置持久保存，请在“设置”窗口中点击“确定”。

## 音乐播放说明

### 播放来源

- 初始模式
  - 播放 `resources.qrc` 中内置的 `music.wav` 与 `elysiam realm.wav` 两首资源。
  - 播放时会把资源先释放到系统临时目录，再交给 Windows MCI 播放。
- 本地模式
  - 默认读取程序运行目录下自动创建的 `music` 文件夹。
  - 在设置中勾选“使用自定义音乐文件夹”后，可改为读取自己选择的目录。
  - 当前实现只扫描 `*.wav` 文件。
- 软件模式
  - 播放器按钮不再播放本地文件，而是模拟 Ctrl+Alt+上一首 / Ctrl+Alt+播放暂停 / Ctrl+Alt+下一首快捷键，用于控制网易云音乐等外部软件。
  - 使用该模式时需要让目标音乐软件保持前台并获得焦点。

### 播放循环

播放器右侧按钮按顺序切换三种模式：

| 图标 | 模式 | 播放到结尾后 |
| --- | --- | --- |
| 随机播放 | 随机 | 随机选一首继续 |
| 列表循环 | 顺序 | 到尾自动回到第一首 |
| 单曲循环 | 单曲 | 重复当前曲目 |

程序通过每 200 ms 查询一次 MCI 播放状态来实现自动切歌，只支持 WAV 文件。

## 设置窗口

在托盘菜单点击“设置”打开。设置窗口可配置：

- 爱莉移动：是否自动移动
- 爱莉说话：是否显示气泡台词
- 爱莉播放音乐：是否启动播放
- 显示播放器：是否显示迷你播放器
- 音乐播放模式：初始模式 / 本地模式 / 软件模式
- 使用自定义音乐文件夹：切换本地音乐目录
- 自定义桌宠：打开“自定义”外观设置窗口

点击“确定”后配置会写入文件，并自动重启程序使配置完整生效。

## 自定义窗口

自定义窗口用于替换整套外观素材：

| 项目 | 说明 |
| --- | --- |
| 设置背景图片 | 设置 / 台词 / 自定义窗口使用的背景图 |
| 设置播放器图片 | 迷你播放器背景图，推荐 332 x 132 |
| 设置常规 GIF | 闲置状态动画 |
| 设置单击 GIF | 单击宠物时的动画 |
| 设置拖动 GIF | 拖动宠物时的动画 |
| 设置初始音乐 | 初始模式中的第 1、2 首 WAV |
| 设置文字及文字框颜色 | 气泡台词文字与边框颜色 |
| 宠物大小 | 宠物窗口尺寸 |
| 合体后上下间距 | 宠物与播放器合体时的垂直间距 |
| 设置台词 | 打开台词编辑窗口 |

图片文件选择支持 PNG / JPG / JPEG，动画为 GIF，音乐为 WAV。所有素材路径写入 `zidingyiwenjian.txt`。

点击“复原”可恢复默认的粉色配色、内置 GIF、内置音乐和默认尺寸。

## 台词编辑

台词窗口把台词分成三组，每组 5 条：

- 闲置台词：自动移动或随机触发时显示
- 单击台词：单击宠物时显示
- 拖动台词：按住拖动时显示

编辑后点击“确定”，台词会写入运行目录下的 `taiciwenjian.txt`。

## 配置与运行数据

程序会在“当前运行目录”（从 Qt Creator 运行时通常是构建目录，发布时通常是 EXE 所在目录）生成和读取以下文件：

| 文件 | 内容 |
| --- | --- |
| `shezhiwenjian.txt` | 常规开关、播放来源、自定义音乐文件夹路径 |
| `zidingyiwenjian.txt` | 外观素材路径、颜色、宠物尺寸、合体间距 |
| `taiciwenjian.txt` | 三组台词 |
| `music/` | 默认本地音乐目录，首次启动自动创建 |

配置采用空格分隔的纯文本格式，因此自定义路径中不要包含空格；当前实现也没有做格式校验。

## 目录结构

```text
桌面宠物播放器/
├─ 源代码/
│  ├─ pet.pro             qmake 工程文件，目标名 ELYSIA
│  ├─ pet.pro.user        Qt Creator 本地工程配置
│  ├─ resources.qrc       Qt 资源清单，编译内嵌素材
│  ├─ main.cpp            程序入口，设置应用名称、版本与图标
│  ├─ widget.h/cpp/ui     主窗口：桌面宠物、托盘、动画、播放控制
│  ├─ musicgui.h/cpp/ui   迷你播放器窗口
│  ├─ form.h/cpp          常规设置窗口逻辑
│  ├─ zidingyi.h/cpp/ui   自定义外观窗口
│  ├─ taici.h/cpp/ui      台词编辑窗口
│  └─ ...                 其余窗口的 .ui 文件
└─ 资源文件/
   ├─ *.gif               闲置 / 单击 / 拖动动画
   ├─ *.wav               内置的两首初始音乐
   ├─ *.png               按钮、播放器与托盘图标
   └─ biao.ico            编译进 EXE 的图标
```

各模块的主要职责：

- `Widget`：宠物透明窗口、气泡文本、随机移动、托盘菜单、动画切换、MCI 播放与自动切歌。
- `musicGUI`：迷你播放器 UI、播放控制信号、拖拽与“合体”跟随，以及软件模式的快捷键模拟。
- `Form`：常规设置窗口，负责收集并持久化开关和播放来源。
- `zidingyi`：外观、素材、尺寸等自定义项的编辑与保存。
- `taici`：三组台词文本的编辑与保存。

## 构建说明

建议使用 Qt Creator 打开 `源代码/pet.pro`，选择 `Desktop Qt 6.8.2 MinGW 64-bit` 等 Qt 6 桌面套件，然后执行“构建”即可生成 `ELYSIA.exe`。也可以使用命令行 qmake 构建：

```powershell
qmake pet.pro
mingw32-make
```

当前仓库是从“源码与资源同目录”的本地工程拆分出来的目录结构，尚未同步调整工程内相对路径。直接按当前布局构建前需要补齐以下内容：

1. `源代码/form.ui` 未包含在仓库提交中，需要从完整 Qt 工程中补回该 UI 文件。
2. `resources.qrc` 与 `pet.pro` 目前仍以“资源文件与工程文件在同一目录”的方式引用素材，例如 `RC_ICONS = biao.ico`；若保持当前目录结构，需要把 `resources.qrc` 内文件改为 `../资源文件/xxx` 的路径，并同步修改 `RC_ICONS`，或把资源文件复制到 `源代码` 目录。

## 实现与设计要点

- 宠物窗口使用 `FramelessWindowHint + WindowStaysOnTopHint + Tool + WA_TranslucentBackground`，因此没有标题栏、任务栏项，适合做桌面挂件。
- 气泡是独立透明小窗口，位置由宠物窗口的 `moveEvent` 持续同步，避免文字遮挡动画。
- 闲置 / 单击 / 拖动三种动画通过同一个 `QLabel` 切换 `QMovie` 实现。
- 自动移动由 `QTimer` 触发，配合 `QPropertyAnimation` 做 1 秒缓动位移动画。
- 播放使用 Windows MCI（`mciSendStringW`），本地资源先写入临时 WAV 文件；暂停、恢复、停止和状态轮询都通过 MCI 命令完成。
- 软件模式使用 `keybd_event` 发送 Ctrl+Alt 组合键，因此代码只能在 Windows 上运行。
- 修改设置或外观后，程序会通过 `QProcess::startDetached` 启动新实例并退出旧实例，保证下次启动即加载最新配置。

## 已知限制

- 仅支持 Windows；自动移动只考虑主屏幕范围。
- 本地播放只扫描 WAV，不包含 MP3、FLAC 等格式。
- 配置与素材路径不支持空格；台词按空格分词保存，台词文本中也不要包含空格。
- “软件音乐”模式只是模拟键盘控制外部软件，不会显示外部软件的播放状态，也没有对网易云音乐窗口做检测。
